# yolo-test 标签判定标准（初步）

> **适用项目**：yolo-test（检测 benchmark）  
> **用途**：标注员打标参考 + 审查员审查依据  
> **范围**：本文**仅覆盖 `viewpoint` 和 `ec_tags`** 的判定标准。`object_labels`（目标框类别）的判定不在本文范围。  
> **基于**：[yolo-test.md](yolo-test.md) §1 labeling config（2026-08-01 修订）  
> **状态**：**初步版本**——随标注实践和审查反馈持续迭代。  
> **总纲**：[README.md](README.md) §7（标签集与 EC 词表的**唯一权威口径**，本文各条不得与之冲突）。

---

## 0. 总则

### 0.1 两条铁律

1. **applicable 即打、含基线**：`ec_tags` 凡是适用于该片的 **一律显式勾选**。绝不用「不勾」隐式表达。纯基线片 = 无任何退化 tag（`normal_light` **可勾可不勾**，见 §2.1；已勾的保留不删，导出侧另行处理）。
2. **片级打标、先裁再标**：`viewpoint` 和 `ec_tags` 是**整条测试片的属性**。如果一条片内条件不统一（如前半模糊、后半清晰），先在 LS 里**裁成多条同质片**，再分别打标。

### 0.2 标签两层

| 层级  | 字段                                   | 粒度    | 标注方式                 |
| --- | ------------------------------------ | ----- | -------------------- |
| 片级  | `viewpoint`（单选）                      | 整条测试片 | 每片必选一个机位             |
| 片级  | `ec_tags`（多选）                        | 整条测试片 | 每片 applicable 即勾,可多选 |
| 源级  | `diff_scope_model` / `diff_operator` | 同源所有片 | 按采集元信息统一打（见 §2.5）    |

> **不在 ec_tags 中打的项**：几何类桶（尺度桶、客观遮挡桶、拥挤/截断桶）由 pipeline 从数据自动派生，**不属于标注 tag**。唯一例外：`severe_occlusion` 是片级**人工主观 flag**，不属于几何桶（见 §2.4）。

### 0.3 本文用法

- **标注前**：通读 §1（机位）、§2（每个 ec_tag 的判据）。
- **拿不准时**：查单项的「正例」「反例」「边界/易混淆」。
- **审查时**：按 §4 速查表逐项核对，特别关注「**不应勾但被勾了**」的反例。
- **发现盲区**：记下标准覆盖不到的真实情况，反馈给标准维护者。

`viewpoint` 是**整片必选的单选字段**（`choice="single"`）。每条测试片**必须且只能**选一个机位。不存在"不确定"或"不选"。

## 2. ec_tags（等价类 tag）

> 本节是本文核心。每条遵循结构：**定义 → 判定标准（勾 / 不勾）→ 正例 → 反例 → 边界**。

### 2.1 成像 / 光照

#### normal_light（正常光照）

**定义**：画面光照正常、均匀、充足，所有目标清晰可见，无偏暗、无过曝、无反光干扰。

**判定标准**：
- **可勾**：整片光照正常，标注员可选择勾选——作为显式标记，方便后续按光照条件切片。即使同时有其他退化（如背景杂乱、严重遮挡），只要光照正常就可勾。
- **不勾也允许**：光照正常的片不勾 `normal_light` 也是可以的——`normal_light` **不作为强制等价类标注**。导出/pipeline 侧可据此推断基线。
- **不必勾**：整片持续偏暗或持续过曝 → 分别勾 `dark` 或 `overexposed`，不必再勾 `normal_light`。

> **已有数据处理**：已标注数据中已勾选的 `normal_light` **保留不删**（避免 Label Studio 导出报错），后续导出时另行处理。

**正例**：刷洗台在标准内镜光源下，画面明亮均匀（可勾可不勾）。

**反例**：
- 整片在暗光环境下 → 勾 `dark`，不必勾 `normal_light`。
- 整片泛白/过曝 → 勾 `overexposed`，不必勾 `normal_light`。

---

#### dark（偏暗）

**定义**：画面整体或大幅区域亮度显著不足，目标细节难以分辨，但尚能辨认（否则无法标注）。

**判定标准**：
- **勾**：整片或大部分帧画面偏暗（可能是因为俯下身子大面积阴影）——器械轮廓可辨但细节（如刻度、纹理）看不清。
- **不勾**：
  - 画面只有局部阴影（如水龙头遮住的光影），整体亮度正常 → 不勾。
  - 暗到完全看不见目标 → 这片本身就无法标注，不应作为测试片使用（采集侧应排除）。

这下面的不标

**正例**：光源调暗、或由于阴影，整体画面灰暗。

**反例**：画面正常亮度，只是某个器械本身是深色的 → 不勾 `dark`（那是物体颜色，不是光照条件）。

**边界**：片中一段暗、一段正常 → **裁成两条片**，暗段勾 `dark`，正常段勾或不勾 `normal_light`。

#### overexposed（过曝 / 逆光）

**定义**：画面大幅区域亮度过高、高光溢出，亮部细节丢失（"白花花一片"）。

**判定标准**：
- **勾**：画面出现大面积过曝——如内镜光源直射台面反光导致半边画面泛白、无法辨认亮区内的目标。
- **不勾**：
  - 仅小面积高光（如器械金属件反光点），画面主体正常 → 不勾（那是正常高光，不算过曝）。
  - 反光水珠造成的水面亮斑 → 走 `glare_water`，不勾 `overexposed`。

（测试集暂未出现，目前先预留着）

**正例**：内镜靠近台面时自动曝光未跟上，台面区域一片白。

**反例**：器械金属表面有一个小反光点（面积 <5%），其余画面正常 → 不勾。

**边界**：`overexposed` vs `glare_water`——过曝是**整体/大面积**的亮度溢出，反光水珠是**水面局部的镜面高光**。两者可能共存（过曝台面上有水珠反光），此时两者都勾。

### 2.2 清晰度

#### fast_blur（快速运动模糊）

**定义**：由于目标或镜头**快速运动**导致的**方向性**模糊拖影（motion blur），目标轮廓沿运动方向拉长/拖尾。

**核心判据（统一标准）**：**以视频整体倾向为准**——长段刷洗、反复取器械等**持续快速动作场景**才标。**仅少数几帧出现方向性拖影的不标。**
![[Pasted image 20260801115540.png|300]]
**判定标准**：
- **勾**：整片**整体倾向**为快速运动场景（如长段清洗刷洗操作、连续多次取换器械），**大部分帧**出现明显方向性拖影——如长刷快速抽出时刷头轮廓拉长、边缘不锐利。
- **不勾**：
  - 片中仅少数几帧（如 <5 帧、或占全片 <10%）偶然出现拖影，其余帧清晰 → **不勾**（不符合"整体倾向"判据）。
  - 目标静止或慢速运动、轮廓清晰 → 不勾。
  - 整片均匀发虚、无方向性 → 那是失焦（`defocus`），不勾 `fast_blur`。但两者**可同时勾**（见下文边界）。

**正例**：
- 长刷从镜体内快速抽出，刷头在画面中拖出一条模糊轨迹——且这一动作贯穿全片大部分帧。
- 操作者持续快速换器械，手和器械反复出现方向性拖影。

**反例**：
- 片中仅 1–2 帧因手突然快速移动出现拖影，其余 98% 的帧清晰 → **不勾**。
- 器械缓慢移动，画面清晰无拖影 → 不勾。

**已有样本复查**：对已标注的样本，按上述统一标准复查——**仅少数几帧模糊但被勾了 `fast_blur` 的，应移除该标签**。

**边界**：**fast_blur + defocus 可同勾**——失焦镜头里出现快速运动，画面既均匀发虚又有方向性拖影（真实数据、理应如此）。判断标准：有方向性 → 勾 `fast_blur`；均匀软 → 勾 `defocus`；两者皆有 → 都勾。

---

#### defocus（失焦）

**定义**：相机对焦不准导致的**均匀模糊**，画面整体变软、边缘不锐利，**无方向性**。与 `fast_blur` 的关键区分：**defocus = 画面整体虚焦不清（均匀软），fast_blur = 运动导致的模糊（方向性拖影）**。
![[Pasted image 20260801115432.png|400]]
**判定标准**：
- **勾**：画面整体或大幅区域均匀发软——所有目标的边缘都模糊，像蒙了一层毛玻璃。无明显的方向性拖影。
- **不勾**：
  - 只有方向性拖影而无均匀发软 → 那是 `fast_blur`。
  - 只有水汽/雾气导致的朦胧 → 那是拍摄介质问题（如镜头起雾），判为 `defocus` 也合理（视觉效果接近失焦）。标注员自行判断，保持同类情况一致性即可。

**正例**：内镜自动对焦失效，整个画面持续发虚。

**反例**：器械本身纹理模糊但边缘锐利 → 不勾。

**边界**：参见 fast_blur 的边界说明。

> **数据增强说明**：`fast_blur`（方向性运动模糊）和 `defocus`（均匀失焦）均可通过数据增强（motion kernel / 高斯模糊）在训练集构造。但 **benchmark test 仍需真实样本**——增强数据不进 test。ec_tag 标注聚焦于"该片整体是否为此条件"的真实判定，用于策展 test 集；不以"增强能不能造"作为是否打 tag 的依据。

### 2.3 表面 / 背景 / 干扰

#### glare_water（反光水珠）

**定义**：清洗台面上的**水/液体的镜面反光**造成的局部高亮区域，通常呈**亮斑或条状闪烁**。核心判据：**水面波动/反光炫目**。

下面两张即使需要标上glare_water 的示例
![[Pasted image 20260801114625.png|300]] ![[Pasted image 20260801115034.png|300]]

**判定标准**：
- **勾**：画面中有明显的水面反光亮斑/炫光。
- **不勾**：
  - 画面中有水但无反光炫目 → 不勾（水本身不是 tag，反光才是）。
  - 器械金属表面的小反光 → 不勾（那是金属高光，不是水面反光）。
  - 大面积过曝（整片泛白）→ 走 `overexposed`。

**正例**：清洗槽内有水，内镜光源照在水面上形成晃动的亮斑。

**反例**：干燥台面无水无反射 → 不勾。

**边界**：`glare_water` + `overexposed` 可同勾——水面反光亮斑密集导致部分区域过曝的，两者 applicable。

---

#### cluttered_bg（背景杂乱）

**定义**：画面**背景**中**墙面悬挂器械数量较多**，视觉上干扰目标识别。核心判据：**墙上挂两三个器械即算杂乱**。**目标本身多（前景器械多）不算** `cluttered_bg`。遮挡严重的情况走独立 tag `severe_occlusion`，不合并进 `cluttered_bg`。
![[Pasted image 20260801115432.png|300]]

**判定标准**：
- **勾**：背景墙面悬挂 ≥2–3 个器械/管路，形成视觉干扰——即使前景目标不多，墙上的器械也增加了画面的杂乱度。
- **不勾**：
  - 画面干净、背景墙面无悬挂物或仅 1 个 → 不勾。
  - 前景目标本身数量多（如操作区多个器械同时在用），但背景墙面干净 → **不勾**（"目标本身多不算"）。
  - 前景目标被手遮挡 → 走 `severe_occlusion`，不因此勾 `cluttered_bg`。

**正例**：操作台后方的墙面上挂着 3 把器械，画面中同时在进行清洗操作，墙面器械构成背景视觉干扰。

**反例**：
- 墙面干净，台面上有 5 个器械同时在用 → **不勾**（目标本身多，不是背景杂乱）。
- 画面中只有一只手 + 一个器械，墙面无悬挂物 → 不勾。

**边界**：`cluttered_bg`（背景杂乱）vs `similar_distractor`（相似干扰物）——杂乱是指**背景墙面悬挂物多**导致视觉负担；干扰物是指**长得像但不是目标**的外部物。两者不同，可同勾。

---

#### similar_distractor（相似干扰物）

**定义**：画面中存在**外观与某类目标相似、但实际不是目标**的外部物体。涵盖以下情况：

- **颜色相近干扰**：白布、白手套等与目标颜色相近的物体，可能误导模型在颜色边界上产生误检；
- **形态相似干扰**：长得像 scope 管身 / 像刷子 / 像注射器但实际不是的物体（如其他类型的管路、线缆、非目标器械）；
- **重叠难辨**：内镜与操作者身体/衣物重叠，导致目标边界难以区分。

![[Pasted image 20260801120912.png|300]]

**判定标准**：
- **勾**：画面中出现了上述任一干扰物。
- **不勾**：画面中只有明确的目标类器械，无任何外观相似的外部物 → 不勾。

**正例**：
- 台面上有非目标型号的管路——粗细、颜色和 scope_mid_section 接近，容易触发误识别。
- 画面中有白布/白手套覆盖或邻近器械，颜色上难以和浅色器械区分。
- 内镜贴近操作者身体，镜体轮廓与身体轮廓重叠，边界模糊。

**反例**：画面中只有明确的目标类器械，无相似外观的外部物 → 不勾。

**边界**：
- 如果**不确定**某物是不是目标类 → 宁可判定为 `similar_distractor`。评测侧需要验证模型会不会在此误检。
- `similar_distractor` 是**整个 clip 级**的 tag——只要片中**某帧**出现了相似干扰物，就勾，不需要每帧都有。

### 2.4 目标可见性

#### severe_occlusion（严重遮挡）

**定义**：操作者的手**大面积遮挡**一个或多个器械，导致器械的关键识别部位（如刷头、针尖、枪嘴、镜体远端）难以辨认。人工主观判断，不依赖几何 IoU 阈值。

![[Pasted image 20260801121035.png|300]]

**判定标准**：
- **勾**：整条测试片中**持续或反复出现**手大面积遮挡器械、影响识别的情况——标注员自己都觉得"我凭经验猜这是什么，而不是看清了是什么"。
- **不勾**：
  - 手只是轻触器械、器械关键部位仍清晰可见 → 不勾（那是轻度遮挡，不属于"严重"）。
  - 器械被**其他器械**遮挡（如 syringe 被 scope 挡住）→ 不勾 `severe_occlusion`（它只针对**手**遮挡器械）。
  - 片中仅 1–2 帧出现严重遮挡、其余帧正常 → 酌情：如果这几帧是这片的核心测试帧（采这片就是为了测遮挡），勾；否则裁片或视情况而定。

**正例**：
- 手握住 air_gun，枪嘴和扳机完全被手指盖住，只能看到握把尾端 → 勾。
- 手包裹住 scope_distal_end，远端头部结构完全不可见 → 勾。

**反例**：
- 手指轻轻搭在 syringe 筒体上，刻度线和推杆都清晰可见 → 不勾。
- scope_mid_section 被另一条 scope 管路遮挡（器械互挡）→ 不勾。
- 画面中器械本身就没有被遮挡 → 不勾。

**边界**：
- `severe_occlusion` 和几何遮挡桶（重遮挡 30–70%、近全遮挡 >70%）是**两套并存、正交**的：几何桶是 pipeline 从数据自动派生的逐帧指标，**不在 ec_tags 中勾选**；`severe_occlusion` 是**人工看完整片后的主观判断**——标注员觉得这片里手严重妨碍了识别，就勾。不用去算 IoU，也不用管几何桶会把这片分到哪一档。
- **关键区分**：`severe_occlusion` 只看**手↔器械**的遮挡关系；器械互挡、器械被台面/管路遮挡 → **不属于** `severe_occlusion`（那些由 pipeline 侧几何桶处理，不在 ec_tags 中体现）。

### 2.5 来源多样性

#### diff_scope_model（异内镜型号）

**定义**：本条测试片使用的**内镜型号**与训练集主要来源不同。

**判定标准**：
- **勾**：采集元信息确认该片来自**不同型号的内镜**（如训练用 Olympus-A、本条用 Olympus-B）。
- **不勾**：型号与训练集主要来源相同。
- **信息缺失**：如果采集侧未标注型号信息，暂不勾，并反馈采集侧补充。**不要凭画面猜测型号**——这是源级元信息 tag，不是画面对比 tag。

**正例**：训练集全是型号 A 的镜下画面，本条片来自型号 B 的镜下画面 → 勾。

**反例**：和训练集同型号 → 不勾。

> **当前状态**（v0.1）：异内镜型号数据源**全缺**——这是已知盲区。`diff_scope_model` 当前是**占位 tag**，待有异型号数据后启用。如果确实出现了异型号源，按上述标准勾选。

---

#### diff_operator（异操作者）

**定义**：本条测试片的**操作者**与训练集主要来源不同。

**判定标准**：
- **勾**：采集元信息确认该片由**不同的操作者**完成（与训练集主要操作者不同）。
- **不勾**：操作者与训练集主要来源相同。
- **信息缺失**：反馈采集侧补充，暂不勾。**不要凭手的大小/肤色/操作风格猜测操作者**。

**正例**：训练集全部由操作者 X 完成，本条片由操作者 Y 完成 → 勾。

**反例**：和训练集同操作者 → 不勾。

> **当前状态**（v0.1）：异操作者数据源**全缺**——同上，`diff_operator` 当前为占位 tag。

## 3. 特殊场景判定

### 3.1 异质片处理

**定义**：一条片内出现**两种或以上不同 ec 条件**（如前半段模糊、后半段清晰）。

**处理流程**：
1. **裁片优先**：在 LS 中按条件边界将异质片裁成多条同质片，分别打 tag。
2. **无法裁分**（如失焦镜头里同时有快速运动）：两者都勾。该帧同时进两个退化桶——这是真实数据，理应如此。
3. **裁完还剩下短暂异质帧**（如全片清晰仅在开头 2 帧失焦）：可忽略这 2 帧（不影响片的整体 tag），或裁掉它们。

### 3.2 负样本与 ec_tag

| 情况 | ec_tag 怎么打 |
|---|---|
| 空帧（画面无任何目标） | 按 applicable 打（如光照正常 → 可勾 `normal_light`） |
| 有相似干扰物（非目标、但长得像） | 勾 `similar_distractor` |
| 画面有目标 + 干扰物共存 | 勾 `similar_distractor`（+ 其他 applicable tag） |

> `similar_distractor` 本质上是一个**负样本 tag**：它告诉评测侧"这片有容易误识别的外部物"——模型不应在其上产生误报。

## 4. 速查表

### 4.1 ec_tags 速查

| tag                  | 一句话判据                   | 可同勾                       |
| -------------------- | ----------------------- | ------------------------- |
| `normal_light`       | 光照正常（**非强制**，可勾可不勾）     | 几乎所有 tag                  |
| `dark`               | 整体偏暗、细节难辨               | glare_water, cluttered_bg |
| `overexposed`        | 大面积过曝泛白                 | glare_water               |
| `fast_blur`          | 整体倾向为方向性拖影（仅几帧不算）       | defocus                   |
| `defocus`            | 均匀发软/发虚（失焦）             | fast_blur                 |
| `glare_water`        | 水面反光炫目                  | overexposed, cluttered_bg |
| `cluttered_bg`       | 墙面悬挂 ≥2–3 器械（前景多不算）     | similar_distractor        |
| `similar_distractor` | 颜色/形态相似 + 身体重叠难辨        | cluttered_bg              |
| `severe_occlusion`   | **手**大面积挡住器械、影响识别（主观判断） | 几乎所有 tag                  |
| `diff_scope_model`   | 异内镜型号（看元信息，勿猜）          | diff_operator             |
| `diff_operator`      | 异操作者（看元信息，勿猜）           | diff_scope_model          |

### 4.2 常见错误速查

| 错误                                         | 为什么错                     | 正确做法                                            |
| ------------------------------------------ | ------------------------ | ----------------------------------------------- |
| 用"不勾"表达"没有这问题"                             | 隐式表达不可靠                  | 显式勾适用的 tag（`normal_light` 例外——可勾可不勾，非强制）        |
| 异质片不裁就标                                    | 一片多条件，tag 不能准确描述         | 先裁成同质片再分别打 tag                                  |
| 仅 2–3 帧模糊就勾 `fast_blur`                    | 以整体倾向为准，少数帧不算            | 整片大部分帧持续/反复出现方向性拖影才勾                            |
| 把器械互挡当 `severe_occlusion`                  | 它只管手↔器械遮挡                | 器械互挡不勾 severe_occlusion                         |
| 前景器械多当 `cluttered_bg`                      | cluttered_bg 看墙面悬挂物，不看前景 | 墙面挂 ≥2–3 器械才勾；目标本身多不算                           |
| 把严重遮挡合并进 `cluttered_bg`                    | 遮挡严重的是独立 tag             | 手挡器械 → `severe_occlusion`；墙挂器械 → `cluttered_bg` |
| 把金属反光当 `glare_water`                       | 水面反光 ≠ 金属高光              | 水面亮斑 → glare_water；金属高光 → 不勾                    |
| 把物体颜色深当 `dark`                             | dark 是光照条件，不是物体颜色        | 整体亮度正常 → 不勾 dark                                |
| 凭画面猜测 `diff_scope_model` / `diff_operator` | 源级 tag 看元信息，不是画面对比       | 信息缺失 → 暂不勾，反馈采集侧                                |
