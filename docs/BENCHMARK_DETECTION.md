# CleanSight Benchmark 等价类划分 · 目标检测（cleansight-yolo）

> 适用数据集：**cleansight-yolo**（8 类目标检测）
> 目的：为 benchmark **test 集人工策展**提供等价类依据（不是训练集划分）
> 前身：本文由 `DATASET_TEST_SCENARIOS.md` 的检测相关维度重排而来，并按讨论结论修订
> 配套：`BENCHMARK_SEGMENTATION.md`（时序分割那一套，独立维护）

---

## 0. 前提与约定

- **测试单元**：单帧（frame）。检测 test 可按帧策展，跨视频抽帧允许。
- **主指标**：逐类 precision / recall、mAP@0.5、mAP@0.5:0.95。
- **bbox 语义（已拍板）**：bbox 表示**该类别在画面中可见**，与"是否在用"无关。
  - 推论：清洗台上未使用的杂物器械**也会被标框**，是合法正样本；不存在"可见但未标"的 precision 误伤。
- **泄漏规则**：test 视频**源级隔离**（整条不进 train/val）；同一视频不抽时间相邻帧。
- **优先级定义**：
  - **P0**：任务核心能力 + 当前覆盖最薄弱 + 失败代价高，benchmark 必测。
  - **P1**：重要难点/边界，应覆盖。
  - **P2 / 基线**：鲁棒性补充，或已饱和、仅作对照基线。
- **数据现状**依据 `DATASET_BALANCE_REVIEW.md`、`DATASET_STATUS.md`、`config.yaml`。

## 1. 评测能力边界（已知盲区）

> benchmark 是尺子，必须诚实声明"量了什么、没量什么"。**绿灯不代表跨域泛化。**

**v0.1 覆盖**：**域内**（同内镜型号 / 同操作者 / 同场景）表现 + **unseen clip**（未见片段/背景）+ **跨固定机位**（cam1↔cam2，见 §2 Group D）。

**泛化轴现状：**

| 泛化轴 | v0.1 状态 | 说明 |
|---|---|---|
| 域内（同型号/操作者/场景） | ✅ 评测 | 评测主体 |
| unseen clip（整源留出） | ✅ 评测 | 视频级留出整条源视频作 test，测"没见过的片段/背景"；**非跨域**，抓的是过拟合特定帧/背景 |
| 异机位 / 角度 | ✅ 评测（P1） | 固定监控有两个机位 cam1（操作者左前）/ cam2（操作者右前）；按 `viewpoint` 切片评 cam→cam 泛化衰减（见 [yolo-test.md](label-studio-pj/yolo-test.md)） |
| 异内镜型号 | ⛔ **盲区** | 无数据源，v0.1 **不评测**，列入 roadmap |
| 异操作者 | ⛔ **盲区** | 无数据源，v0.1 **不评测**，列入 roadmap |

> 跨型号/操作者泛化是已知盲区——benchmark 通过**不能**推断模型在异型号/异操作者上可用。待数据可得后补 `e2e_test` 通道单独评。

### Group A — 类别 × 尺度（核心主轴）

分组沿用 `config.yaml`：`group1_large`（大目标）/ `group2_small`（小目标）。
优先级由**稀缺程度 + 小目标难度**驱动。

| 等价类（类别） | 尺度组 | 性质 | 现状（实例/上下文） | 来源 | 优先级 |
|---|---|---|---|---|---|
| hand | 大 | V | ✅ 占比 ~53%（最高） | 派生 | 基线 |
| scope_control_body | 大 | V | ✅ 充分 | 派生 | 基线 |
| scope_mid_section | 大 | V | ✅ 充分 | 派生 | 基线 |
| scope_distal_end | 小 | V | ⚠️ 小目标 | 派生 | P1 |
| syringe | 小 | V | ⚠️ 1190，仅 flush 单场景 | 派生 | P1 |
| short_brush | 小 | V | ⚠️ 910；×flush 仅 135 | 派生 | P1（flush 侧 **P0**） |
| **air_gun** | 小 | V | ⚠️ **394，仅 air_injection** | 派生 | **P0** |
| **brush_tip_out** | 极小 | V | ❌ **318，全集最稀缺** | 派生 | **P0** |

> 稀缺合法组合（判分时单独看）：`air_gun×air_injection`=367、`brush_tip_out×long_brush_insert`=118、`×long_brush_withdraw`=151、`short_brush×flush`=135。

### Group B — 视觉难度（pairwise 交叉）

各维度相互近似独立，用 pairwise 覆盖；越偏极端叠加越难。

## 3. 数据增强可构造性评估

> **红线：增强样本原则上不进 benchmark test。** benchmark 量的是真实世界表现，合成图只能证明"扛得住某种变换"，证明不了真实偏暗/反光下的能力。
> 因此本节结论的用途是 **train 侧补覆盖**（如 `augment.py`，仅对 train）；benchmark test 仍需真实策展。唯一例外「空帧负样本」本就真实存在于数据，直接捞。

判定档位：✅ 忠实增强（图像/时间变换可还原）｜⚠️ 近似（有保真风险）｜❌ 必真实采集｜🆓 免费真实。

| EC | 构造方式 | 手段 / 保真度 |
|---|---|---|
| 空帧负样本 | 🆓 | 直接取无目标帧，不增强不采集 |
| 偏暗 | ✅ | 亮度/gamma↓ |
| 过曝/逆光 | ✅ | 亮度↑/高光裁剪 |
| 严重失焦 | ✅ | 高斯模糊 |
| 快速运动模糊 | ✅ | 方向 motion kernel；从相邻真实帧合成更真 |
| 边缘截断 | ✅ | 平移/裁剪让目标出画 |
| 极小尺度/远景 | ⚠️ | 下采样能模拟"小"，模拟不了远景成像（景深/大气） |
| 重遮挡/近全遮挡 | ⚠️ | cutout/random-erasing；人工块不如真实手遮挡；"允许漏检"边界类可接受 |
| 反光/水珠 | ⚠️ | 合成高光叠加，物理保真低 |
| 密集共现/拥挤 NMS | ⚠️ | copy-paste 多实例，有合成痕迹 |
| 稀缺类"补量"（air_gun/brush_tip_out） | ⚠️ | 旋转/缩放/亮度复制已有实例——补**数量**行，补**姿态/视角多样性**不行 |
| 背景杂乱 | ❌ | 需真实器械/管路 |
| 相似干扰物 | ❌ | 需真实相似物体 |
| 目标离场 enabled=False | ❌ | 标注语义，非增强可造 |
| 异机位/角度 | ❌ | 必真实重录 |
| 异内镜型号 / 异操作者 | ❌❌ | 增强绝对造不出，且暂无源（见 §1 盲区） |

**小结**：可靠靠增强省掉采集的，集中在**帧级成像条件**（偏暗/过曝/失焦/运动模糊/边缘截断），且只进 train。语义/几何多样性/来源均需真实。

## 4. 优先级汇总

> 泛化相关项区分"可执行"与"阻塞"：跨型号/操作者见 §1，暂不计入 v0.1 可执行 P0。

**P0（现有数据可执行的必测核心）**
- 稀缺小目标类检测：`air_gun`（394/单上下文）、`brush_tip_out`（318，全集最稀缺）
- 极小尺度 <1% 远景检测
- unseen clip（整源留出）——现有数据可做的最强泛化项

**P0（阻塞，待数据）**
- 异内镜型号泛化 ⛔（见 §1，暂不计入可执行 P0）

**P1（重要难点/边界）**
- `scope_distal_end` / `syringe` / `short_brush` 小目标
- 重遮挡、边缘截断、目标离场缺席
- 密集共现、拥挤重叠 NMS
- 快速运动模糊（尤其 brush_tip_out）
- 偏暗、反光/水珠、背景杂乱
- 空帧负样本
- 异机位/角度（固定机位 cam1/cam2，✅ 可评测，P1）；异操作者 ⛔（阻塞）

**P2 / 基线**
- 大目标三件 + hand（已饱和，作对照基线）
- 检测下限 <0.3%、近全遮挡 >70%、严重失焦、过曝（边界，允许漏检）
- 相似干扰物防误检

## 5. 手标 vs 自动派生（策展分工）

- **自动派生（不手标）**：类别、尺度、**客观遮挡**、边缘截断、共现密度、拥挤重叠——全部由 **bbox 几何**算（面积占比、与 hand 的 IoU、触边、同帧数量、互 IoU）。这就是"检测 EC 不该逐帧手标"的原因。
- **手标（时间窗口，一段一段）**：运动模糊、偏暗、反光、背景杂乱、相似干扰物、过曝——归入 LS benchmark 项目的 `ec_env` TimelineLabels，标一整段覆盖其中所有帧。
- **片级人工 flag（整片打,非逐帧）**：`yolo-test` 的 `ec_tags` 里 `severe_occlusion`（严重遮挡）——凭目测主观判断、不绑几何 IoU 阈值,标记「为测严重遮挡而裁的同质片」;与上面的客观遮挡几何桶**正交并存**,不替代。
- **源级（选片时定）**：来源多样性（型号/操作者/机位）。

## 6. test 集策展与指标切片

1. **源级隔离**：benchmark test 视频整条从 train/val 排除，写入 `benchmark_test.yaml`。
2. **策展目标**：让 test 在 P0/P1 等价类上**密集**（尤其小目标 + 难点维度），而非反映日常帧分布。
3. **每帧打 EC 标签** → 生成覆盖矩阵，逐 EC 桶核对（对照本文 P0/P1 是否 ✅），并标出 §1 盲区未覆盖项。
4. **指标切片**：除全局 mAP 外，按 EC 桶分别报逐类 P/R/mAP —— 例如「极小尺度桶的 air_gun recall」「重遮挡桶 mAP」「偏暗桶 vs 正常桶的衰减」「unseen clip vs seen 的衰减」。
5. **冻结版本**：定版打 tag（如 `benchmark-det-v0.1`），只增不改；盲区项在版本说明里显式列出。
